**신한은행 PG 메인페이지 클론 코딩**
----------------------------------------------------------
신한은행 전자지급결제대행(PG) 서비스 웹사이트를 퍼블리싱 학습 목적으로 제작한 클론 코딩 프로젝트입니다.

<br>

### 📌 프로젝트 소개
신한은행 PG 서비스 공식 홈페이지를 참고하여 HTML/CSS/JS 퍼블리싱 역량 향상을 목적으로 제작하였습니다.


<br>

### ⚙️ 사용 기술

| 분류 | 기술 |
|---|---|
| 마크업 | HTML5, CSS3 |
| 스크립트 | JavaScript, jQuery 3.3.1 |
| 슬라이더 | Swiper.js |
| 애니메이션 | GSAP 3, ScrollTrigger, Scrolla, Splitting.js |
| 스크롤 | Lenis (smooth scroll) |
| 아이콘 | Font Awesome |
